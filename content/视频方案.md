# 视频号方案 v1

> 每周一条，30–35 秒，固定三段结构。目标是**每周能稳定产出**，不是做爆款。

---

## 一、基本参数

| | |
|---|---|
| 时长 | **30–35 秒（硬上限 35）** |
| 画幅 | 1080 × 1920 竖版 |
| 节奏 | 一屏一个数字，**3 秒一屏** |
| 结构 | 钩子 → 跌了 → 涨了 → 该等 → 收尾 |
| 口播字数 | **≤ 130 字**（约 5 字/秒） |

## 二、画面结构：一屏一张榜

**不要一条一屏地切。** 一屏放一整张榜单，所有条目同屏可见；配音念到哪条，白卡片滑到哪条，其余行压暗。

理由：一条一屏的节奏像 PPT 翻页，观众看不到"总量"和"排名"；一张榜停住，观众先扫一眼全貌，再跟着高亮往下走，信息密度高得多。

三张榜，顺序固定：

| 榜 | 条数 | 讲法 |
|---|---|---|
| 跌得最狠 | 3 条 | 一句带过整体，再逐条点名 |
| 涨得最狠 | 4 条 | 同上 |
| 先别碰 | 2 条 | 一句话打包，不用逐条念 |

每张榜配一个标题（跌得最狠 / 涨得最狠 / 先别碰）、一个口径说明（本周 · 农业农村部）、一句画外音式的小注（叶菜整体在跌）。

## 三、节奏

| 时间 | 内容 |
|---|---|
| 0–3.5s | 开场：给一个最反常的数字 |
| 3.5–11s | 榜一出现 → 三条依次高亮 |
| 11–22s | 榜二出现 → 四条依次高亮 |
| 22–27s | 榜三出现 → 两条一起亮 |
| 27–31s | 收尾：该买的趁现在，该等的别急 |

总长 **31 秒左右**，上限 35。

每条字幕 ≤ 12 字。数字只保留一位小数，口径写在榜头，不念出来。

## 四、本期示例（2026-10-18）

| 屏 | 字幕 | 数据来源 |
|---|---|---|
| 钩子 | 有一样东西，一周涨了 46.7% | CPI 数据存储设备环比 |
| 跌 | 菠菜便宜 10.5%、生菜 9.7%、平菇 7.9% | 农业农村部第 40 周 |

## 五、生成方式

一条命令出全部素材：

```powershell
python tools/make_video_cards.py
```

产物在 `output/<日期>/视频/`：`card-01.png` … `card-10.png`、`字幕.srt`、以及手写的 `口播稿.md` / `分镜.md`。

图卡模板是固定的，每期**只改脚本顶部的 `EPISODE` 数组**（数字、名称、品类、来源、时长），版式不用动。

再跑一条命令，直接出成片：

```powershell
python tools/make_video.py
```

它会做三件事：把每句话合成配音（Windows 自带语音，离线）、按配音长度分配每张卡的时长、逐帧渲染后编码成 MP4（1080×1920 / 30fps，带缓慢推近、出入画和底部进度条）。

产物：`output/<日期>/视频/今天贵不贵.mp4`，约 2.5 MB，35 秒。

配音是系统自带的合成音，能用但偏机械。如果以后接了云端 TTS（火山引擎），把 `_tts/` 里的 wav 换掉重跑即可，脚本不用改。

## 六、每期交付物

我会产出这一组，你只需要导入剪映、配音、发：

1. **图卡 PNG** 6–8 张（1080×1920）
2. **字幕文案**（逐句，带时间轴，可批量导入）
3. **口播稿**（念得顺的短句版，不是书面语）
4. **分镜表**（画面 / 字幕 / 时长 / 转场）
5. **封面图**（视频号 1080×1440 一版）
6. **标题候选** 3–5 条

## 七、生产流程

```
周四  更新数据（站内现有流程）
周五  生成素材包：选题 → 图卡 → 字幕 → 口播稿
周五晚 你配音 + 剪映合成
周六  发布
```

每期总耗时控制在 40 分钟内，其中你实际动手约 15 分钟。

## 八、配音选型

**结论：前几期直接用剪映内置 AI 配音，不要上云。**

理由：每期约 120 字，一个月 500 字。任何云服务的成本都是几分钱，**成本不是决策因素**；而接 API 要注册、实名、拿 key、写脚本，为 35 秒的视频不值当。

等出现下面任一情况再上云：

- 想要固定的、有辨识度的音色（剪映音色大家都能用）
- 想克隆自己的声音
- 想把「生成音频」并进一键流程

云服务对比（价格以官网为准，2026-10）：

| | 火山引擎（豆包语音） | 腾讯云 | 阿里云百炼 |
|---|---|---|---|
| 计费 | 约 3.5–4.5 元/万字符（阶梯） | 约 2.6–3 元/万字符 | 按字符，约 0.8 元/万字符 |
| 免费额度 | 有体验额度 | 超自然大模型音色有免费额度 | 90 天额度（限部分地域） |
| 中文自然度 | 口碑最好 | 好 | 好 |
| 声音复刻 | 支持 | 支持 | 支持 |
| 我们的月成本 | < 0.1 元 | < 0.1 元 | < 0.1 元 |

真要用云，选**火山引擎**：中文断句和语气最自然，复刻音色可选，文档清楚，按字符计费在这个量级几乎为零。

## 九、不要做的事

- 不做超过 35 秒的版本，宁可少讲一条
- 不念数据来源（画面角标标就行），念了拖节奏
- 不在一期里讲两个主题，一周只有一个"最反常的数"
- 不做"预测"，只讲已经发生的变化
