# 视频号方案 v1

> 每周一条，30–35 秒，固定三段结构。目标是**每周能稳定产出**，不是做爆款。

---

## 一、基本参数

| | |
|---|---|
| 时长 | **30–35 秒（硬上限 35）** |
| 画幅 | 1080 × 1920 竖版 |
| 节奏 | 一屏一个数字，**3 秒一屏** |
| 结构 | 钩子 → 跌了 → 涨了 → 该等 → 收尾 |
| 口播字数 | **≤ 130 字**（约 5 字/秒） |

## 二、逐秒结构

| 时间 | 画面 | 作用 |
|---|---|---|
| 0–3s | 全屏一个数字 | 钩子，只给最反常的那一个 |
| 3–13s | 「跌了」三条 | 每条约 3.3 秒，一张卡一个数 |
| 13–23s | 「涨了」三条 | 同样节奏，形成预期 |
| 23–30s | 「该等」两条 | 给行动，不给分析 |
| 30–35s | 收尾 | 一句建议 + 引导关注 |

三段固定，观众第二次看就知道在哪一段找自己要的东西。

## 三、文案模板

每周只换数字和品类名，句式不动：

```
钩子：本周有一类东西，一周涨了 {X}%。
跌了：{A} 便宜 {a}%，{B} 便宜 {b}%，{C} 便宜 {c}%。
涨了：{D} 涨 {d}%，{E} 涨 {e}%，{F} 涨 {f}%。
该等：{G} 和 {H} 先别碰，位置太高。
收尾：该买的趁现在，该等的别急。数据每周更新。
```

**规则**

- 每条字幕 ≤ 12 字，念得完
- 数字只保留一位小数，不念口径（"元/斤""环比"这些放到画面角落）
- 不出现"建议投资""赶紧买"这类表述，只做事实描述

## 四、本期示例（2026-10-18）

| 屏 | 字幕 | 数据来源 |
|---|---|---|
| 钩子 | 有一样东西，一周涨了 46.7% | CPI 数据存储设备环比 |
| 跌 | 菠菜便宜 10.5%、生菜 9.7%、平菇 7.9% | 农业农村部第 40 周 |
| 涨 | 存储涨 46.7%、平板 23.6%、奶粉 30% | CPI / 站内奶粉 |
| 等 | 内存、显卡先别碰，位置 90 分位以上 | 站内 pct5 |
| 收尾 | 该买的趁现在，该等的别急 | — |

## 五、生成方式

一条命令出全部素材：

```powershell
python tools/make_video_cards.py
```

产物在 `output/<日期>/视频/`：`card-01.png` … `card-10.png`、`字幕.srt`、以及手写的 `口播稿.md` / `分镜.md`。

图卡模板是固定的，每期**只改脚本顶部的 `EPISODE` 数组**（数字、名称、品类、来源、时长），版式不用动。

## 六、每期交付物

我会产出这一组，你只需要导入剪映、配音、发：

1. **图卡 PNG** 6–8 张（1080×1920）
2. **字幕文案**（逐句，带时间轴，可批量导入）
3. **口播稿**（念得顺的短句版，不是书面语）
4. **分镜表**（画面 / 字幕 / 时长 / 转场）
5. **封面图**（视频号 1080×1440 一版）
6. **标题候选** 3–5 条

## 七、生产流程

```
周四  更新数据（站内现有流程）
周五  生成素材包：选题 → 图卡 → 字幕 → 口播稿
周五晚 你配音 + 剪映合成
周六  发布
```

每期总耗时控制在 40 分钟内，其中你实际动手约 15 分钟。

## 八、配音选型

**结论：前几期直接用剪映内置 AI 配音，不要上云。**

理由：每期约 120 字，一个月 500 字。任何云服务的成本都是几分钱，**成本不是决策因素**；而接 API 要注册、实名、拿 key、写脚本，为 35 秒的视频不值当。

等出现下面任一情况再上云：

- 想要固定的、有辨识度的音色（剪映音色大家都能用）
- 想克隆自己的声音
- 想把「生成音频」并进一键流程

云服务对比（价格以官网为准，2026-10）：

| | 火山引擎（豆包语音） | 腾讯云 | 阿里云百炼 |
|---|---|---|---|
| 计费 | 约 3.5–4.5 元/万字符（阶梯） | 约 2.6–3 元/万字符 | 按字符，约 0.8 元/万字符 |
| 免费额度 | 有体验额度 | 超自然大模型音色有免费额度 | 90 天额度（限部分地域） |
| 中文自然度 | 口碑最好 | 好 | 好 |
| 声音复刻 | 支持 | 支持 | 支持 |
| 我们的月成本 | < 0.1 元 | < 0.1 元 | < 0.1 元 |

真要用云，选**火山引擎**：中文断句和语气最自然，复刻音色可选，文档清楚，按字符计费在这个量级几乎为零。

## 九、不要做的事

- 不做超过 35 秒的版本，宁可少讲一条
- 不念数据来源（画面角标标就行），念了拖节奏
- 不在一期里讲两个主题，一周只有一个"最反常的数"
- 不做"预测"，只讲已经发生的变化
