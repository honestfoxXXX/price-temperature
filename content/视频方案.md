# 视频号方案 v1

> 每周一条，30–35 秒，固定三段结构。目标是**每周能稳定产出**，不是做爆款。

---

## 一、基本参数

| | |
|---|---|
| 时长 | **30–35 秒（硬上限 35）** |
| 画幅 | 1080 × 1920 竖版 |
| 节奏 | 一屏一个数字，**3 秒一屏** |
| 结构 | 钩子 → 跌了 → 涨了 → 该等 → 收尾 |
| 口播字数 | **≤ 130 字**（约 5 字/秒） |

## 二、画面结构：一屏一张榜

**开场必须给数字，不给标题。** 前 3 秒直接甩两个极端值（+46.7% 和 −10.5%），配上"涨疯了 / 跌得狠"，比任何标题都快。

**不要一条一屏地切。** 一屏放一整张榜单，所有条目同屏可见；配音念到哪条，白卡片滑到哪条，其余行压暗。

理由：一条一屏的节奏像 PPT 翻页，观众看不到"总量"和"排名"；一张榜停住，观众先扫一眼全貌，再跟着高亮往下走，信息密度高得多。

三张榜，顺序固定：

| 榜 | 条数 | 讲法 |
|---|---|---|
| 跌得最狠 | 3 条 | 一句带过整体，再逐条点名 |
| 涨得最狠 | 4 条 | 同上 |
| 先别碰 | 2 条 | 一句话打包，不用逐条念 |

每张榜配一个标题（跌得最狠 / 涨得最狠 / 先别碰）、一个口径说明（本周 · 农业农村部）、一句画外音式的小注（叶菜整体在跌）。

## 三、节奏

| 时间 | 内容 |
|---|---|
| 0–3.3s | 开场：两个极端数字砸进来（+46.7% / −10.5%） |
| 3.5–11s | 榜一出现 → 三条依次高亮 |
| 11–21.2s | 榜二出现 → 四条依次高亮 |
| 21.4–22.9s | 榜三出现 → 两条一起亮 |
| 23–27.5s | 收尾 + 关注引导 |

总长 **28.7 秒**，上限 30 秒。

收尾卡只做三件事：给一句行动结论、给一个更新承诺、给一个关注按钮。

**不要在结尾贴网址。** 视频号里链接点不开，观众也不会手打一长串英文域名——贴了等于没贴。要引流就把话说清楚："每周日更新，关注不吃亏"。网址只放在公众号文章和主页简介里。

每条字幕 ≤ 12 字。数字只保留一位小数，口径写在榜头，不念出来。

## 四、本期示例（2026-10-18）

| 屏 | 字幕 | 数据来源 |
|---|---|---|
| 钩子 | 有一样东西，一周涨了 46.7% | CPI 数据存储设备环比 |
| 跌 | 菠菜便宜 10.5%、生菜 9.7%、平菇 7.9% | 农业农村部第 40 周 |
| 涨 | 存储涨 46.7%、平板 23.6%、奶粉 30% | CPI / 站内奶粉 |
| 等 | 内存、显卡先别碰，位置 90 分位以上 | 站内 pct5 |
| 收尾 | 该买的趁现在，该等的别急 | — |

## 五、生成方式

一条命令出全部素材：

```powershell
python tools/make_video_cards.py
```

产物在 `output/<日期>/视频/`：`card-01.png` … `card-10.png`、`字幕.srt`、以及手写的 `口播稿.md` / `分镜.md`。

图卡模板是固定的，每期**只改脚本顶部的 `EPISODE` 数组**（数字、名称、品类、来源、时长），版式不用动。

再跑一条命令，直接出成片：

```powershell
python tools/make_video.py
```

它会做三件事：把每句话合成配音（Windows 自带语音，离线）、按配音长度分配每张卡的时长、逐帧渲染后编码成 MP4（1080×1920 / 30fps，带缓慢推近、出入画和底部进度条）。

产物：`output/<日期>/视频/今天贵不贵.mp4`，约 2.5 MB，35 秒。

配音是系统自带的合成音，能用但偏机械。如果以后接了云端 TTS（火山引擎），把 `_tts/` 里的 wav 换掉重跑即可，脚本不用改。

## 六、每期交付物

我会产出这一组，你只需要导入剪映、配音、发：

1. **图卡 PNG** 6–8 张（1080×1920）
2. **字幕文案**（逐句，带时间轴，可批量导入）
3. **口播稿**（念得顺的短句版，不是书面语）
4. **分镜表**（画面 / 字幕 / 时长 / 转场）
5. **封面图**（视频号 1080×1440 一版）
6. **标题候选** 3–5 条

## 七、生产流程

```
周四  更新数据（站内现有流程）
周五  生成素材包：选题 → 图卡 → 字幕 → 口播稿
周五晚 你配音 + 剪映合成
周六  发布
```

每期总耗时控制在 40 分钟内，其中你实际动手约 15 分钟。

## 八、配音

**当前用 `edge-tts`**（微软 Edge 在线神经语音，免费，不需要 key）。

```powershell
python tools/make_voice.py     # 生成 13 条配音
python tools/make_video_board.py   # 合成成片
```

默认音色 `zh-CN-YunyangNeural`（男 · 资讯播报），语速 +18%。换音色改 `tools/make_voice.py` 顶部的 `VOICE`：

| 音色 | 特点 |
|---|---|
| `zh-CN-YunyangNeural` | 男 · 资讯播报，念数字最稳（默认） |
| `zh-CN-YunxiNeural` | 男 · 温柔叙事，偏生活感 |
| `zh-CN-XiaoxiaoNeural` | 女 · 通用，最自然但也最容易被听出是 AI |
| `zh-CN-YunjianNeural` | 男 · 激昂，适合做反差强烈的选题 |

**为什么不用火山**：火山语音的 API key 一直返回 `45000030 requested resource not granted`——key 能通过认证，但对应的应用没开通语音合成服务。要用火山（尤其是复刻自己的声音），需要控制台里那个应用的 **APP ID + Access Token** 两个值，走 `v1/tts` 接口。

**为什么不用 Windows 自带 SAPI**：`Microsoft Huihui` 是 2010 年代的拼接音，一听就知道是机器。edge-tts 的神经音色差了一个时代。

**最好的选择仍然是真人录音**：35 秒约 105 字，念三遍挑一遍，5 分钟的事，而且是你自己的声音。

## 九、不要做的事

- 不做超过 30 秒的版本，宁可少讲一条
- 不写"大家好，今天我们来聊聊"这类开场，第一秒就要有数字
- 不念数据来源（画面角标标就行），念了拖节奏
- 不在一期里讲两个主题，一周只有一个"最反常的数"
- 不做"预测"，只讲已经发生的变化
