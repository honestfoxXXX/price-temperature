# 周日发布流程

更新时间：2026-10-25。用户每周手动触发；不设置自动发布或定时任务。

## 1. 数据核验先行

- 打开官方原文，记录URL、页内发布日期、统计期、批发/零售范围、比较基期。
- 核验日不等于统计期。没有新周报时沿用最近已核实报告并写明日期，不伪造当周涨跌。
- CPI同比、月环比、周报周环比不能混用；不把行业指数直接套到某型号。
- 无可复核时间序列，不展示“近五年分位”“四年涨价结论”；反推锚点不是实测历史。
- 未核实条目保留目录但隐藏旧报价和购买结论。更正必须同时进入网站、视频与文章。

## 2. 更新网站

更新数据及核验记录后运行：

```powershell
python tools/build.py
node tools/smoke.js
python tools/make_og.py
```

人工检查首屏、弹层、统计口径；通过后提交推送，并抓取GitHub Pages线上页面验证版本。
不自动运行旧的seed_history脚本充实真实序列，以免把推算点当观测。

## 3. 视频：直接交付成片

本期入口：

```powershell
# 先写本期 data/episode-YYYY-MM-DD.json，全部数据来自已核实原文。
# VOLC_KEY 从环境读取，不写入仓库；默认沿用用户的复刻音色。
python tools/weekly_release.py 2026-10-25 voice
python tools/weekly_release.py 2026-10-25 render
python tools/weekly_release.py 2026-10-25 assets
```

- 使用复刻音色 S_Dvf6T9yi2，复用已生成火山配乐，低音量铺底。
- 每期选题由数据决定：提问、反差或解释，不固定“暴涨悬念”句式。
- 1080×1920、30fps、通常25—30秒，硬上限35秒。
- 左右各104px安全边距；关键文字和字幕不能贴边。
- 同屏总览、讲到哪条就高亮；真口播字幕另附SRT，画面字幕可作精简摘要。
- 只讲可证实变化，不保证完播率，不把价格高等同将来会跌。
- 保存本期配音脚本、音频清单和时间轴，避免换期时旧音频串入。

## 4. 长图与公众号

```powershell
python tools/make_weekly.py 2026-10-25
```

- 长图保留本期已核实内容和关于数据，隐藏历史待核验卡片、信源长列表和更新日志。
- 临时HTML必须保留网站根路径，保证截图品牌图标正常加载。
- 公众号保持简单：一句导语 → 嵌入视频号视频 → 网站长图 → 地址。
- 需要时添加简短统计期说明和更正；不再复制整段口播造成冗长。
- 交付公众号横版封面、视频号3:4/9:16封面及发布字段文案。

## 5. 发布与验收

- 用户自行登录发布：视频号发出后，把对应视频插入公众号文章。
- 阅读原文填写网站URL；平台链接入口的可选类型以实际页面为准。
- 按平台实际要求声明AI复刻配音与AI配乐，不承诺对推荐量的影响。
- 验证视频能完整解码、时长/字幕/音轨正常；看首帧、榜单、结尾和手机缩略预览。
- 检查长图底部无更新日志；保存当期完整素材包。
- 观察真实播放与完播数据再迭代，不宣称固定发布时间或早期播放权重的未经证实规则。
