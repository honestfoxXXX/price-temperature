# 周日发布流程

每周日晚上跑一遍，全程约 40 分钟，其中你真正动手的约 20 分钟。

核心原则：**先更新网站，再从网站生成视频和文章**。顺序反了会出现文章里的数和页面上的数对不上。

---

## 一、更新网站（我，约 15 分钟）

```powershell
cd D:\价格监控

# 1. 可选：刷新食品类真实月度序列（联网，约 30 秒）
python tools/scrape_food.py

# 2. 合并序列、追加当期快照
python tools/seed_history.py

# 3. 改 data/prices.json：价格、涨跌、结论、asOf、changelog
#    改 data/watchlist.json：本周新增的监控条目
#    改 data/cpi.json：统计局新一期分项（每月一次即可）

# 4. 重新生成（会先校验）
python tools/build.py

# 5. 重新生成分享图
python tools/make_og.py

# 6. 冒烟测试
node tools/smoke.js

# 7. 推送上线
git add -A
git commit -m "更新 YYYY-MM-DD"
git push
```

推送后约 40 秒，<https://honestfoxXXX.github.io/price-temperature/> 就是新的。

---

## 二、生成长图（我，一条命令）

```powershell
python tools/make_weekly.py
```

产物在 `output/<日期>/`：

| 文件 | 用途 |
|---|---|
| `长图.jpg` | **公众号里贴这张**，750 宽，手机上一比一显示不糊 |
| `长图.png` | 无损版，需要放大看细节时用 |

自动做三件事：测量页面真实高度 → 按 750 宽整页截图 → 转 JPG 压缩。

---

## 三、做视频（我出素材，你剪，约 10 分钟）

按 `content/视频方案.md`：30–35 秒，跌了 / 涨了 / 该等三段。

我交付：图卡 PNG、逐句字幕、口播稿、分镜表。

你做：导入剪映 → 加配音（先用剪映内置 AI 配音）→ 导出 → 发视频号。

---

## 四、发公众号（你，约 5 分钟）

文章不用长，三段就够：

```
【标题】这周有一样东西涨了 46.7% | 今天贵不贵

（此处插入视频号的视频）

（此处插入一张长图：output/<日期>/长图.jpg）

本周 70 个条目里，19 条值得现在买、18 条建议再等等。
完整数据在 👉 https://honestfoxXXX.github.io/price-temperature/

#物价 #生活成本 #省钱
```

标题里的数字每期换掉，句式保留——这是让读者形成预期的地方。

---

## 五、发布后（可选，2 分钟）

- 看一眼公众号后台的「阅读来源」，视频号带来的占比
- 如果某一条数据被留言问到，说明它值得下期展开
- 把当天的 `output/` 目录留着，月底可以拼一张月度对比图

---

## 每周固定的时间线

| 时间 | 事项 |
|---|---|
| 周日 20:00 | 更新数据、推送、生成素材 |
| 周日 20:30 | 剪视频、发视频号 |
| 周日 21:00 | 发公众号 |
| 周日 21:10 | 结束 |

固定时间发，比内容质量更能养成阅读习惯。
